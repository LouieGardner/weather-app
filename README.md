# Weather Forecast Application

A responsive weather forecasting web application built using HTML, CSS and JavaScript.

## Overview

This application uses the OpenWeather API to retrieve real-time weather data for cities worldwide. Users can input the name of a city to view current temperature, humidity and weather conditions with the inclusion of dynamic weather icons depending on the weather.

## Features

- Real-time weather data retrieval
- City search functionality
- Dynamic weather icons
- Temperature and humidity display
- Error handling for invalid locations
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- OpenWeather API
